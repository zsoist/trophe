## Current screen selection candidate

The client now publishes a bounded selection from the actual AnatomyExplorer controls or the successfully loaded exercise detail. GlobalCoach displays a removable selection chip and captures the hint only when the user sends a message with screen context enabled. Exact pathname matching, publisher ownership cleanup and exercise actor matching prevent an old route or account from supplying the next turn's selection. Loading a different exercise remounts its loader and clears the previous selection. Whole-body and unresolved or ambiguous mesh selections clear the narrow hint; upper/lower leg regions are used only for a currently selected leg group.

The server independently resolves catalogue group/subgroup membership or the exact authorized curated database exercise. Browser labels are display-only. Parent-muscle matches remain explicitly partial; no geometry, activation percentage or clinical claim is added. Local draft plans and professional subject selection are not connected by this change. The client bridge imports no server resolver or anatomy catalogue.
