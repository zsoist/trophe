# UX research: Cronometer + fast workout logging (2026-08-19)

Trigger: Nik feedback — "app works great but a little boring; steal ideas from
Cronometer; workout logging too extensive; want very very fast recording."

## Cronometer signature patterns (nutrition)
1. Nutrient target bars, color-coded status per nutrient → adapt as gold bars, curated "Top 6" card (avoid their density complaint).
2. User/coach-pinned highlighted nutrients → coach sets client's priority micros (differentiator).
3. Energy summary ring (consumed/burned/remaining + macro donut) as single anchor.
4. Free barcode + curated USDA/NCCDB data (trust) — keep barcode free, badge verified entries.
5. Multi-select copy/paste across days → "Copy yesterday's [meal]" one-tap chip on empty meals.
6. Recents/favorites-first search, ranked by time-of-day.
7. Streaks where ANY entry counts (low-bar, toggleable).
8. Tap food → full nutrient breakdown + "% of your remaining target" context.
9. Trends tab + "Nutrient Oracle" (foods highest in X) → coach-facing trends, weekly one-insight card for clients.
10. Timestamped meal grouping (they paywall it; we ship free).

## Fast workout logging (Hevy/Strong/Fitbod)
1. One-tap routine start from home cards; History → "Save as Template".  → SHIPPED (My routines + Repeat last).
2. Ghost previous-values prefill + tap-checkmark accept. → already shipped (July wave).
3. Auto rest timer per exercise; lock-screen set logging (later). → per-exercise targets shipped July.
4. Plate calculator. → shipped July.
5. "Just did it" logging (reps-only/done-only); quick-logged flag visible to coach. → SHIPPED (quick-done).
6. PR noise: opt-in banner, working sets only, tracked lifts only. → SHIPPED (compound-only PRs).
7. Templates never lock mid-session; prompt to update after. (follow-up)

## Split-based quick start
- Fitbod: open app → suggested workout from muscle recovery + split pick (push/pull/upper/lower). → SHIPPED (split chips → history-aware suggestions in picker).
- Hevy: routine folders named by split. (follow-up: rotation "next in split")
