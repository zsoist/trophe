## Pitfalls captured
- Migrations touching storage.*/auth.* must be schema-guarded (CI = plain Postgres).
- CI-wait bash loops must gate the merge on a captured CI_OK var — a loop `break`
  doesn't set `$?`, so `&&`-chaining a merge after the loop can merge on RED.
- React Compiler: removing an impure call (Date.now()) from a manual useCallback can
  flip a silent compiler bailout into a hard "manual memoization could not be
  preserved" error — drop the manual memo (plain fn) and let the compiler own it.
